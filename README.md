# (주)부루넷 | Burunet Corp

AI를 활용한 소프트웨어 전문 개발 회사 (주)부루넷의 공식 홈페이지입니다.

## 기술 스택

- React 19 + TypeScript
- Vite

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속합니다.

## 빌드

```bash
npm run build
npm run preview
```

## 페이지 구성

- **Hero** — 메인 비주얼 및 회사 소개
- **About** — 회사 개요 및 핵심 역량
- **Products** — 주요 제품·솔루션 (IT 인프라 AI, Manxai HRM, 건강·스포츠 앱)
- **Business** — 사업 분야 및 채용 안내
- **Contact** — 문의 폼
- **Footer** — 회사 정보 및 바로가기
